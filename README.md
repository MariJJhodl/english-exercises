# English Exercises

A mini-website of interactive English exercises, built to help a student train and master her English skills — and available to anyone who wants to improve their English.

## What's inside

Each session is organised by date and covers grammar, vocabulary and pronunciation. Exercises include:

- **Fill in the blank** — vocabulary and grammar choices with instant feedback
- **Build the sentence** — word reordering to practise adjective, adverb and object placement
- **Read aloud** — pronunciation practice with highlighted words and links to audio references
